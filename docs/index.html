Shallot

A macOS menu-bar app that runs a Tor SOCKS5 proxy on 127.0.0.1:9050. Click to turn it on or off; the icon shows whether it is off, bootstrapping, connected or failed.

Download Shallot.dmg Apple silicon · macOS 13 or later · source on GitHub

Why Arti, not a tor daemon

Arti is the Tor Project's Rust implementation, and it is a library. Shallot is one app with Tor compiled in: no Homebrew, no launchd service, no torrc, nothing left running when you quit.

The cost: Arti is younger than C tor and has had less scrutiny, and Shallot has no bridges or pluggable transports. If you need those, run tor.

Install, and the Gatekeeper step

Open the DMG and drag Shallot to Applications. It is ad-hoc signed and not notarized, so macOS blocks the first launch. Clear that with:

xattr -dr com.apple.quarantine /Applications/Shallot.app

Or open it, click Done, then System Settings → Privacy & Security → Open Anyway. Control-click → Open no longer works on macOS 15 and later. Or build it yourself.

Point an app at it

SOCKS5 proxy, host 127.0.0.1, port 9050. In Sparrow Wallet: Settings → Server → Use Proxy. .onion addresses work. To check it:

curl --socks5-hostname 127.0.0.1:9050 \
  https://check.torproject.org/api/ip

The listener binds to loopback only; there is no setting to change that.
